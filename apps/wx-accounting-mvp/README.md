# 轻记账微信小程序 MVP

这是一个本地优先的微信记账小程序 MVP，不依赖 npm、后端或云开发。可以直接用微信开发者工具导入目录运行。

## 已实现

- 首页展示本月收入、支出、结余、预算进度和最近账单
- 首页原地快速记账，减少页面跳转等待
- 完整记账页支持新增和编辑
- 账单列表支持月份筛选、编辑、删除
- 本月收入/支出分类统计，支持月份切换
- 自定义支出分类、收入分类和账户
- 本月预算设置与剩余额度提示
- JSON 导出到剪贴板、从剪贴板导入
- 从剪贴板识别常见账单 CSV 并合并导入
- 清空本地数据

## 导入方式

1. 打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择本仓库的 `apps/wx-accounting-mvp`
4. AppID 可以先选择测试号或使用自己的小程序 AppID

## 数据存储

当前数据只保存在本机微信小程序环境：

- `wx_accounting_mvp_bills`: 账单记录
- `wx_accounting_mvp_config`: 分类、账户、本月预算
- `wx_accounting_mvp_version`: 最近更新时间戳

换手机、换微信环境或清缓存会导致本地数据不可见。上线前建议优先补云同步或提醒用户定期导出。

## MVP 约束

CSV 导入目前是启发式识别，适合做第一版验证。微信/支付宝不同导出格式可能需要继续加适配器。

## 后续优先级

1. 为微信/支付宝账单分别做稳定解析器
2. 自定义分类/账户删除与排序
3. 周期记账
4. Go 后端同步
5. AI 自动分类和自然语言记账
