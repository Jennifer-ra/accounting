# 轻记账微信小程序 MVP

这是一个微信记账小程序。第一阶段保持原生小程序实现，同时支持纯本地模式和云端模式。

## 已实现

- 首页展示本月收入、支出、结余、预算进度和最近账单
- 首页原地快速记账，减少页面跳转等待
- 完整记账页支持新增和编辑
- 账单列表支持月份筛选、编辑、删除
- 本月收入/支出分类统计，支持月份切换
- 自定义支出分类、收入分类和账户
- 本月预算设置与剩余额度提示
- 纯本地模式：数据只保存在微信本地缓存
- 云端模式：微信登录后通过 Go API 保存到 MySQL，并缓存本地快照
- JSON 导出到剪贴板、从剪贴板导入
- 从剪贴板识别常见账单 CSV 并合并导入
- 清空本地数据

## 导入方式

1. 打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选择本仓库的 `apps/wx-accounting-mvp`
4. AppID 可以先选择测试号或使用自己的小程序 AppID

## 云端模式开发配置

1. 启动 `services/go-api`
2. 打开小程序设置页
3. 确认 API 地址为 `http://localhost:10240/api/v1`
4. 打开“云端模式”开关
5. 点击“登录并同步”

开发环境后端默认 `WECHAT_MOCK_LOGIN=true`，不依赖真实微信密钥。生产环境必须关闭 mock，并配置真实小程序 AppID 和 Secret。

## 数据存储

本地缓存 key：

- `wx_accounting_mvp_bills`: 账单记录或云端快照
- `wx_accounting_mvp_config`: 分类、账户、本月预算
- `wx_accounting_mvp_cloud_settings`: 云端模式和 API 地址
- `wx_accounting_mvp_token`: 后端登录 token
- `wx_accounting_mvp_version`: 最近更新时间戳

云端模式下，MySQL 是主数据源，本地缓存只负责首屏速度、离线展示和迁移兜底。

## MVP 约束

CSV 导入目前是启发式识别，适合做第一版验证。微信/支付宝不同导出格式需要继续加稳定适配器。
