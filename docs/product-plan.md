# Product Plan

## Positioning

A lightweight, local-first WeChat Mini Program for people who want fast daily bookkeeping without account setup in the MVP stage.

## MVP Strengths

- Low friction: fast entry from the home page
- Clear privacy story: data stays in WeChat local storage during MVP
- Developer friendly: no npm, no backend, easy to import in WeChat DevTools
- Expandable: monorepo structure supports future Go API and import tools

## Next Product Priorities

1. Stable WeChat Pay CSV importer
2. Stable Alipay CSV importer
3. Category and account deletion/sorting
4. Recurring bills
5. Reminder and budget warning
6. Go backend sync
7. AI-assisted category detection and natural language entry

## Launch Plan

1. Polish GitHub repository and keep it public.
2. Publish developer article with implementation details.
3. Publish user-facing post focused on privacy and low friction.
4. Invite 5-10 users to try the Mini Program in WeChat DevTools or via an experience QR code.
5. Choose the next feature based on feedback, with bill import likely first.
